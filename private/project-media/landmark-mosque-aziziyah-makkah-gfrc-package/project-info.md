Religious / Mosque Architecture

## Location
Al Aziziyah District, Makkah, Saudi Arabia

GFRC/GRC mosque architectural works including ornate minarets, decorative domes, carved façade details, Islamic ornamentation, mashrabiya-style openings, calligraphic bands, and refined exterior architectural elements.

- Carved calligraphic architectural detailing
- Mashrabiya-style window and screen elements
- High-finish GFRC/GRC craftsmanship
- Religious architectural identity in Makkah
